# ⚓ ballast

**자신을 믿지 않는, Claude Code 목표 엔진.**

목표를 건네세요 — 캠페인이든, 코드베이스든, 한 번도 안 해본 분야든. ballast는 Claude가 결과를 "주장"하는 게 아니라 "획득"하도록 구조를 겁니다: 답을 쓰기 전에 지형부터 훑고, 뼈대를 전부 세우고, 기반지식을 원자 단위로 분해하고, 조각 하나하나를 검증한 뒤에만 믿고, 토대부터 완성까지 쌓아 올립니다.

철학이 작동하는 10초:

> **사용자:** "저 싼 모델도 괜찮아 보이는데 — 그냥 그걸로 바꿔"
> **ballast** *(Claude가 답하기 전에 규칙이 주입됨)*: "사용자가 고정한 것은 바꾸지 않는다. 제안만 하고, 결정은 사용자가."
> **Claude:** "이 모델은 8월 13일에 직접 고정하셨어요(원장 D-012). 비교표를 드릴 테니 — 결정은 사용자 몫입니다."

Claude가 조심하려고 기억해 낸 게 아닙니다. 시스템이 조심함을 배달했습니다.

## 구성

| 조각 | 종류 | 하는 일 |
|---|---|---|
| **goal** | 스킬 | 엔진 본체. 지형 스캔(답보다 질문 먼저) → 전체 뼈대 → 원자 잎, 하나하나 검증 후에만 하중 부담 → 재점검 루프 → 완료는 선언이 아니라 검증 |
| **rules hook** | 훅 | 상시 규칙을 걸리는 메시지마다 본문 전체로 자동 주입. 위험 패턴은 차단. 같은 말은 한 번만 |
| **pin** | 스킬 | 방금 한 교정을 한 번에 영구 규칙으로 |
| **verify-gate** | 스킬 | 조사·지식은 관문 통과 전까지 초안: 반박 우선·원출처 2+·표본·한계·라벨 |
| **decision-ledger** | 스킬 | 추가만 되는 결정 원장 — 번복은 조용한 수정이 아니라 대체 링크 |
| **proof-standard** | 스킬 | 진실 파일에 증거 없는 제품 주장 금지. 코드 상태 4단계 불혼용 |
| **brain-init** | 스킬 | 기억 구조(인덱스·원장·미해결·세션로그·제품진실) 골격 생성 |

실제로 굴러간 체계에서 증류했습니다: 비개발자 한 사람이 몇 달간 — 처음 해보는 분야까지 포함해 — 업무 전체를 Claude Code로 돌렸고, 그 결과를 버티게 해준 조각들에서 회사 정보를 걷어낸 것입니다.

## 설치

```
/plugin marketplace add svy04/ballast
/plugin install ballast@ballast
```

rules hook은 의존성 없는 스크립트 하나라 `node`(18+)만 있으면 됩니다. 나머지는 전부 마크다운입니다.

## 빠른 시작

1. `/ballast:goal <큰 목표>` — 전체 파이프라인. 처음 분야면 답을 만들기 전에 그 분야의 질문·함정·표준 도구부터 수집합니다.
2. 작게 시작하려면 `/ballast:brain-init` — 기억 구조만 깝니다.
3. 아무거나 한 번 교정해 보세요 → Claude가 **pin**(규칙으로 박기)을 제안 → 그 규칙은 이후 걸리는 모든 메시지에 자동으로 도착합니다.

## rules hook 동작

카탈로그는 두 곳을 합쳐 읽습니다(중복 id는 프로젝트가 이김): `~/.claude/ballast.rules.json`(개인 규칙) + `<프로젝트>/.claude/ballast.rules.json`(프로젝트 규칙).

- `keywords` 부분일치 / `patterns` 정규식 / `always: true` 매 메시지(1~2개까지만)
- `action: "block"` — 주입 대신 프롬프트를 세우고 사유 표시
- 주입 상한 = 12개·약 6,000자. 상한에 걸리면 카탈로그를 쳐낼 때
- 끄기 `BALLAST_DISABLE=1`, 진단 `BALLAST_DEBUG=1`. 카탈로그가 깨져도 세션은 안 깨집니다
- 시작은 [`rules/ballast.rules.example.json`](rules/ballast.rules.example.json) 복사, 또는 그냥 **pin**에게 맡기기

## 위생 — 뭐든 공개하기 전에

Claude로 운영한 작업 공간에는 안 보는 곳에 비밀이 쌓입니다. 2026년에만 npm 패키지 수백 개가 `.claude/settings.local.json`을(일부는 살아있는 자격증명째) 실어 배포했고, 대형 회사가 서명된 앱 안에 내부 CLAUDE.md를 동봉한 사례가 공개 보고돼 있습니다. 첫 푸시 전에 [docs/PUBLISH-CHECKLIST.md](docs/PUBLISH-CHECKLIST.md)를 한 줄씩 밟으세요.
