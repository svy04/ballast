# ⚓ ballast

**Claude Code를 위한 규율 레이어 — AI 세컨드 브레인이 표류하지 않게.**

Claude를 외부 기억(결정·조사·제품 사실·진행 업무)으로 쓸 때 진짜 문제는 "잊어버리는 것"이 아닙니다. **표류(drift)** 입니다 — 검증 안 된 주장이 반복되며 "사실"로 굳고, 과거 결정이 조용히 다시 쓰이고, 존재하지 않는 기능에 대한 자신만만한 카피가 나갑니다.

ballast는 그 반대 무게추입니다(배 밑바닥에 실어 배가 뒤집히지 않게 하는 짐). 플러그인 하나, 조각 다섯:

| 조각 | 종류 | 하는 일 |
|---|---|---|
| **rules hook** | 훅 | 매 메시지를 규칙 카탈로그와 대조해, 걸리는 규칙의 **본문 전체**를 작업 시작 전에 주입. 위험 패턴은 차단도 가능 |
| **decision-ledger** | 스킬 | 추가만 되는 `DECISIONS.md` — 결정은 수정·삭제 없이, 대체(supersede) 기록과 양방향 링크로만 바뀜 |
| **verify-gate** | 스킬 | 조사 결과와 모델 지식은 관문 통과 전까지 초안: 반박 우선, 원출처 2개 이상, 표본 수, 한계 명시, 90일 신선도. 다른 회사 AI로 2차 검증(선택) |
| **proof-standard** | 스킬 | 진실 파일에 증거 없는 제품 주장 금지. 코드 상태 4단계(구현/연결/운영/검증)를 절대 섞지 않음 |
| **brain-init** | 스킬 | 어느 프로젝트든 기억 구조(인덱스·원장·미해결·세션로그·제품진실)를 깔아줌 |

실제로 굴러간 체계에서 증류했습니다: 비개발자 한 사람이 몇 달간 업무 전체를 Claude Code로 운영했고, 그 체계를 정직하게 유지해 준 조각들에서 회사 고유 정보를 걷어낸 것이 이 플러그인입니다.

## 설치

```
/plugin marketplace add svy04/ballast
/plugin install ballast@ballast
```

rules hook은 의존성 없는 스크립트 하나라 `node`(18 이상)만 PATH에 있으면 됩니다. 나머지는 전부 마크다운입니다.

## 빠른 시작

1. `/ballast:brain-init` — 현재 프로젝트에 `memory/` 구조와 세션 시작 규칙을 깔아줍니다.
2. [`rules/ballast.rules.example.json`](rules/ballast.rules.example.json)을 `<프로젝트>/.claude/ballast.rules.json`으로 복사하고, 진짜 지킬 규칙만 남기고 쳐냅니다.
3. 평소처럼 일합니다. 결정을 확정하면 원장에 박히고, 조사하면 주장마다 라벨이 붙고, 제품 카피를 쓰면 진실 파일을 인용하고, 위험 패턴을 치면 에이전트가 보기 전에 막힙니다.

## rules hook 동작

CLAUDE.md는 한 번 로드되지만 긴 세션은 거기서 멀어지고, 상시 규칙 40개는 관련 있든 없든 매 요청 컨텍스트를 잡아먹습니다. 훅은 이걸 뒤집습니다 — 규칙은 카탈로그에 살고, 메시지마다 **그 메시지에 걸리는 규칙만** 본문 전체로 주입됩니다.

카탈로그는 두 곳을 합쳐 읽습니다(중복 id는 프로젝트가 이김):

1. `~/.claude/ballast.rules.json` — 개인 규칙(모든 프로젝트)
2. `<프로젝트>/.claude/ballast.rules.json` — 그 프로젝트 규칙

- `keywords` — 대소문자 무시 부분일치 / `patterns` — 정규식 / `always: true` — 매 메시지 주입(1~2개까지만)
- `action: "block"` — 주입 대신 프롬프트를 세우고 `body`를 사유로 표시
- 주입 상한 = 규칙 12개·약 6,000자 — 상한에 걸리면 상한을 늘릴 게 아니라 카탈로그를 쳐낼 때입니다

끄기: `BALLAST_DISABLE=1`. 진단: `BALLAST_DEBUG=1`. 카탈로그가 깨져도 세션은 절대 깨지지 않습니다(조용히 무시하도록 설계).

## 위생 — 뭐든 공개하기 전에 읽을 것

Claude로 운영한 작업 공간에는 안 보는 곳에 비밀이 쌓입니다: `settings.local.json`, 세션 기록, 메모리 파일. 2026년에만 해도 npm 패키지 수백 개가 `.claude/settings.local.json`을(일부는 살아있는 자격증명째) 실어 배포한 사례, 대형 회사가 서명된 모바일 앱 안에 내부 `CLAUDE.md`를 동봉한 사례가 공개 보고돼 있습니다. [claudleak](https://github.com/hazcod/claudleak) 같은 스캐너가 존재하는 이유입니다.

Claude로 운영한 저장소에서 처음 푸시하기 전에 [docs/PUBLISH-CHECKLIST.md](docs/PUBLISH-CHECKLIST.md)를 한 줄씩 밟으세요.

## 선례와 정직 고지

이 README는 자기 자신에게 verify-gate 라벨을 적용합니다: **2026년 8월 기준**, 메시지별 **규칙 본문** 주입(가장 가까운 선례는 스킬 *이름* 추천 훅), 양방향 supersede 링크가 있는 단일 append-only 결정 원장(가장 가까운 선례는 결정당 파일 1개 방식), 무증거 주장 금지 기준이 붙은 제품 진실 파일 — 이 세 가지를 하는 공개 프로젝트를 찾지 못했습니다. `못 찾음` ≠ `없음` — 선례를 아시면 이슈로 알려주세요. 여기 링크하겠습니다.
